# Java FFM (JEP 454) + C++ learn_ffm DLL Implementation Plan

**Goal:** Runnable JEP 454 FFM overview topic: Java downcalls into a CMake-built C ABI DLL (`learn_ffm`) with several `add*` functions; elegant monorepo wiring; then document VS Code native attach.

**Architecture:**
- CMake **SHARED** target `learn_ffm` under `src/cpp/ffm/` (C ABI, `extern "C"`).
- **Exclude** `src/cpp/ffm/**` from `learn_cpp` GLOB (critical).
- DLL/SO output: `${CMAKE_BINARY_DIR}/bin` (same as `learn_cpp` runtime dir).
- Java topic `s04_ffm_overview_jep454` uses `SymbolLookup.libraryLookup` + `Linker.downcallHandle`.
- Gradle: `--enable-native-access=ALL-UNNAMED` + resolve `learn.ffm.dir` (env / property / scan `build/*/bin`).
- Optional `scripts/build-ffm-native.cmd` (vcvars64 → cmake preset → `--target learn_ffm`).

**Tech:** JDK 25, FFM `java.lang.foreign`, C++23, clang-cl + Ninja, Windows x64 DLL.
